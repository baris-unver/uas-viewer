# SkyG Airframe Explorer

Interactive 3D models of SkyG Speed 90B (`c6b/`); the site root opens SkyG Speed 90B. Exploded view, per-part print data, camera noses, section cuts, CG and neutral-point marks. Single static page (three.js/WebGL); open `index.html` or the GitHub Pages site.

Generated from the design project by `scripts/viewer_C4.py` (SkyG Speed 120B: `scripts_C7B/viewer_C4.py`); published with `scripts/publish_site.sh` / `scripts_C7B/publish_site.sh`.
