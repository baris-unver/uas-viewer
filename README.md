# SkyG Airframe Explorer

Interactive 3D models of SkyG Speed 90 (revision C6-9, `c6/`, also the site root), SkyG Speed 90B (carbon-tube fuselage, `c6b/`), SkyG Speed 120 (`c7/`), SkyG Speed 120B (50 mm carbon tube, `c7b/`) and SkyG Speed 180 (`c8/`); SkyG Speed 60 (`c5/`) is archived: exploded view, per-part print data, camera noses,
section cuts, CG and neutral-point marks. Single static page (three.js/WebGL); open `index.html` or the GitHub Pages site.

Generated from the design project by `scripts_C7B/viewer_C4.py`; published with `scripts_C7B/publish_site.sh`.
