# SkyG Airframe Explorer

Interactive 3D models of SkyG Speed 90 (revision C6-8, `c6/`, also the site root), SkyG Speed 120 (`c7/`) and SkyG Speed 180 (`c8/`); SkyG Speed 60 (`c5/`) is archived: exploded view, per-part print data, camera noses,
section cuts, CG and neutral-point marks. Single static page (three.js/WebGL); open `index.html` or the GitHub Pages site.

Generated from the design project by `scripts/viewer_C4.py`; published with `scripts/publish_site.sh`.
